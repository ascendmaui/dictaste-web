# Security Policy

## Reporting a vulnerability

Report security vulnerabilities through a private GitHub security advisory on this repository:

https://github.com/ascendmaui/dictaste-web/security/advisories/new

Include enough detail to reproduce the issue and the impact you believe it has. Do not open a public issue for an unpatched vulnerability.

## General support

For bugs, questions, and other non-security requests, use GitHub Issues:

https://github.com/ascendmaui/dictaste-web/issues
